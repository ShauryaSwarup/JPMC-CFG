## 📝Description
- Difficulty in collating and managing a large volume of data, events, and progress associated with various initiatives.
- Challenges in keeping track of project details, monitoring progress in real-time, and streamlining operations.
- Inefficiencies caused by manual work involved in data collection and management.

By addressing these issues, Navsanjeevan can enhance their data management, improve real-time monitoring, and streamline their operations.

## 📈Progress

#### Web Dev
- Separate Dashboards: Activists and Program Managers have dedicated dashboards for streamlined workflow management.
- Progress Tracking: Activists can easily upload and update beneficiary progress, facilitating real-time monitoring.
- Activist Data Access: Program Managers can access activist data and view programs organized by activists.
- Testimonials: Showcase beneficiary reviews and testimonials to highlight the positive impact of programs.
- Sales for Empowerment: Support sales activities to endorse woman empowerment initiatives.
- Real-Time Data Collection: Enable real-time data collection to ensure accurate and up-to-date information.
- User Authentication: Implement secure user authentication to safeguard data and access control.
- Session Management: Maintain user sessions for a seamless and personalized experience.
- Cookie Tracking: Utilize cookie tracking for improved user interactions and preferences.

## 🔮Future Scope
- Offline Capabilities: Enhance the platform to support offline functionality, allowing users to work even without an internet connection.
- Virtual Training: Integrate virtual training modules to provide remote learning opportunities and expand reach.
- Mobile App: Develop a dedicated mobile application to enable easy access and usage of the platform on smartphones and tablets.
- AI/ML Data Analysis: Implement AI/ML algorithms for advanced data analysis, deriving valuable insights and optimizing decision-making processes.

## 🛠Project Setup

1. Clone the repository
```
https://github.com/cfgindia2023/Team-3
```
To start the frontend user interface
```
cd frontend
npm install
npm start
```
To start the backend server
```
cd backend
npm install
npm run dev
```
